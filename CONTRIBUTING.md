# Contributing

Start with docs/TESTER_GUIDE.md and AGENTS.md. Use a branch and test data. Keep generated client/server code under `serverpod generate`, and create a migration for database model changes. Run the supplied checks and verify the preview behavior before opening a pull request. Report Cloud launch separately from local checks.

Do not commit runtime data, password files, Cloud credentials, private project bindings or private product code. Do not publish unexercised app links or claim fresh Codespaces startup/deployment was verified when it was not.
